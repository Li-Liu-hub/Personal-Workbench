# 百科：编码规范与后端八股扩充

新增 **118 个知识点 + 118 道关联练习**，并为既有 Java 生态包的 133 道练习补齐训练画像。内容方向来自开源社区维护的知识库与官方文档，讲解、示例与练习为本项目原创编写，每条目保存对应来源链接。

## 使用

使用包含本次内容的新版程序，首次打开会自动增量导入。

- 百科顶部“全部领域”选择 **Java**，分类选择 **编码规范**，或搜索“命名”“魔法值”“subList”。
- 选择 **后端**：分类 **设计模式**（创建型/结构型/行为型）、**Redis**（原理与运维、缓存场景）、**消息队列**。
- 选择 **Python**，分类 **进阶专题**，搜索“GIL”“装饰器”“深浅拷贝”。
- 进入条目可查看示例、边界说明、自检和参考结论，并通过关联练习提交作答。
- Java 生态包的关联练习现在带能力方向与难度画像：训练推荐按八个方向正确分组，不再落入通用兜底文案。

## 训练画像（存量规范化）

`assets/curriculum_profiles.json` 为 java_ecosystem 的 133 张关联练习补齐已校对画像：能力方向按条目分类映射（并发/Java 核心→Java 与并发，Spring/工程/分布式→工程可靠性，数据访问/中间件→数据库，Web/安全→网络与 Web，JVM→性能与交付），难度按主题深度取 1–3，练习目标取条目摘要，作答要求取题面任务句。画像走客户端映射路径，不回写题库 JSON，不触碰用户数据库中的既有记录。

## 重要边界

- 编码规范条目以《Java 开发手册》黄山版为基准，示例用于判断与改错；手册全文以 [p3c 仓库](https://github.com/alibaba/p3c) 与官方英文版为准。
- Redis 原理条目以 Redis 7.2 为前提；主从复制、哨兵与集群的生产参数以 redis.io 文档为准。缓存一致性给出的是主流方案的时序与边界，不承诺绝对一致。
- 消息队列条目按 Kafka 3.x / RocketMQ 5.x / RabbitMQ 3.13 表述；advanced-java 内容遵循 CC-BY-SA-4.0，本包仅引用其观点主题并自写讲解，来源链接逐条保存。
- 设计模式条目给出 Java 17+ 实现要点与常见误用边界，不替代 [java-design-patterns](https://github.com/iluwatar/java-design-patterns) 的完整示例与测试。
- Python 条目以 CPython 3.10+ 行为为基准；实现相关结论（如小整数缓存、字符串驻留）不得跨实现套用。
