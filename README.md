# Rust 个人办公台

个人使用的 Windows 桌面办公工具，集中管理账号密码、网站收藏、快捷路径、文件、文档、图书、联系人和物品，内置网页聊天与 PowerShell。开发需求和当前实现边界见 [个人办公台开发文档](个人办公台开发文档.md)。

## v0.3.4 使用入口

- 当前版本点击左下方“更新 → 检查更新 → 安装更新并重启”。后续发布会更新本机 `updates/latest.json`，使用者不需要编译。更新会重启应用；Rust 代码修改仍由开发端编译发布。
- “大模型聊天”内置 WebView2 网页标签页，支持 DeepSeek、ChatGPT 和自填网址。网站收藏的打开按钮进入此页面；登录资料独立保存在本地浏览器目录。
- 文件页操作栏固定在顶部，PowerShell 按钮在当前文件夹下方打开终端。“撤回 / Ctrl+Z”恢复本版本删除的文件，重启后仍可撤回；旧版本移入回收站的文件通过系统回收站恢复。
- 联系人增加生日、专业、照片和详情分类；照片保存到数据库。弹窗居中，每次打开从姓名开始。
- 物品增加购买日期、购买价格和丢弃日期，列表可直接修改名称、数量、位置、日期、价格与分类，点保存生效。
- 记录条目点击星标收藏并置顶；左侧功能导航右键也可收藏置顶。收藏与标签互不影响。
- 文档使用页面内白纸编辑区；“图书”支持新增页面、页面标签页、分类筛选、自动保存、冲突保护和草稿恢复。
- 设置中可开关开机自启动。对外保留 `个人办公台.exe`，更新成功后旧版本入口自动归档到 updates 子目录；数据位置配置文件需要保留。

## 0.3.4 交互修复

PowerShell 增加明确的命令输入框和执行按钮，回车执行后可继续输入下一条命令；启动及输入管道在后台处理，持续输出也不会占住界面。内置浏览器按实际切换更新原生视图，离开网页后归还键盘焦点，展示加载进度和失败信息。首次打开提供 DeepSeek / ChatGPT 入口。

## 功能

- 启动直接进入快捷路径，不设置首页或工作台；无需创建账号或登录。
- 所有功能均可在右上方切换“宫格 / 列表”，支持账号、快捷路径及文件夹内容、文档、物品、网站、联系人和设置。点击查看详情，右键管理或删除；宫格末尾为添加卡片，列表末尾为添加行。
- 全部页面共用浅色画布，标题、视图切换和操作集中在首行，搜索框与搜索/清空按钮固定显示在紧邻的下一行；移除上下分割栏、宣传卡片和操作说明。自定义主题继续生效。添加、详情、编辑等对话框始终位于整个窗口正中心。
- 网站或软件账号按普通文本保存在本机。密码始终直接显示，可编辑和复制；没有隐藏开关、自动隐藏、登录、锁定或密钥验证。
- 账号名称、账号和明文密码可在列表或宫格原位直接输入；输入区域有边框，改动后就地显示保存/取消，详情按钮仍可打开完整卡片。复制按钮优先使用当前输入值，保存仅更新这三个字段，保留备注、网址和标签。账号详情使用更大的字号、整行字段和像素对齐的字体渲染。
- 账号、物品、快捷入口、文档、联系人、网站和小工具各自提供自定义标签及全部/未分类/标签筛选；列表提供分类下拉框，宫格用简洁标签展示，点击详情或右键设置分类；账号分类选择后立即保存，物品列表与其他字段一起点保存；右键“设置标签”也可选择多个标签，支持创建、重命名、删除。搜索和标签同时生效，视图切换保留筛选。文件夹内容按文档、图片、视频、音频、压缩包、程序、其他或文件夹筛选，可叠加名称搜索。
- 联系人保存姓名、学校、工作、手机号、身份证号、地址、性别、爱好和聊天笔记；卡片详情内可添加多份聊天记录，支持搜索、编辑、右键删除。
- 网站收藏保存名称、网址、分类和备注；支持模块搜索、查看编辑、复制网址、打开网站和右键删除。
- 每个功能顶部均有“导出”，可导出当前功能的全部记录或全部办公台数据；设置页也提供全部导出入口。ZIP 内包含 UTF-8 JSON、文档原件、草稿和完整数据库快照。快捷路径只导出地址，不打包指向的外部文件夹。
- 搜索框实时筛选当前功能；输入停止 300 毫秒后自动查询已索引文件内容，也可点击搜索或按回车立即查询，清空恢复完整列表。账号搜索包含名称、账号、密码、网址、备注和标签，且与分类筛选同时生效。已索引的文件内容直接显示在快捷路径和文档页面，不设置单独的搜索结果页。
- 文件夹和文件以等宽等高的方块展示；点击文件夹在办公台内浏览，并可新建、重命名、复制、移动或删除后撤回。
- 快捷路径中的文件单击选中、双击使用系统关联程序打开；也可右键打开。台内文档仍点击进入写作编辑器。
- 外部文件可拖到已打开的文件夹空白处、子文件夹条目或快捷文件夹卡片，后台复制并刷新；使用实时拖入位置，兼容 Windows 拖拽期间没有普通鼠标移动事件的情况。原件保留，同名项目自动加“副本”序号，失败展示具体项目。
- 文件及文件夹条目、文件快捷入口和台内文档提供“复制”按钮，使用 Windows 文件剪贴板，可直接到资源管理器粘贴；文件夹页面选中文件也可 Ctrl+C。按住条目拖到资源管理器等支持文件拖拽的目标，可向外复制文件，原件保留。
- 点击添加文档直接在程序内填写标题和正文，无需选择文件路径；内容自动保存在办公台文档目录。标题独立保存，允许同名文档。
- 需要文件副本时，可主动导出 Markdown、TXT 或包含正文的 Word 文档；导出不改变台内文档。
- 记录物品名称、分类、数量、存放位置和备注，支持新增、编辑、删除与筛选。
- 文本自动保存，检测到外部改动时暂停覆盖；可将恢复草稿保存成新文档。

## 从源码运行

需要 Windows x64、Rust 1.95 或更新版本，以及 rust-toolchain.toml 指定的 GNU 编译工具链。

PowerShell 下可运行：

~~~powershell
.\scripts\build.ps1
~~~

脚本会先运行格式检查、Clippy 和自动化测试，再生成发布版，并复制到 dist\个人办公台.exe。默认将构建文件放在系统临时目录下的英文路径，避免 MinGW 在包含中文字符的工作路径中链接失败。

也可以手动运行：

~~~powershell
cargo run
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
~~~

## 数据位置与旧版兼容

默认数据目录为当前 Windows 用户的 `%LOCALAPPDATA%\PersonalDesk`。`desk.db` 保存账号、快捷路径、物品清单、联系人及聊天记录、文档记录和文件搜索索引，账号密码是普通文本；文档和恢复草稿保存在同目录下的普通文件中。程序不提供登录、权限验证、加密保存或自动锁定。

升级时会只读检查旧版 `vault.db`，将当前电脑可读取的账号自动迁移到 `desk.db`，原文件保留。迁移标记与账号在同一事务内保存，避免重复导入；修改过的账号不会被旧版数据覆盖，已删除的账号不会重新出现。无法读取的旧记录保留原文件并提示，不阻止进入程序或添加新账号。

台内文档保存后更新标题和正文索引，外部文件夹的正文索引需手动更新。文档自动保存和外部修改检查用于避免内容丢失。

## 本机数据位置与导入导出

发布目录可放置 `personal-desk-data-path.txt`，其中一行绝对路径可固定已有数据目录，避免 Windows 打包与普通启动时的数据目录差异。当前交付版本已指向本机录入的数据；移动程序时一并保留此文件。

批量导入可使用 `个人办公台.exe --import-data 输入.json`，JSON 包含 `accounts` 和可选 `websites` 数组，字段对应领域模型；完全重复账号和同网址收藏跳过，原有不同记录保留。导入事务失败不会留下半批数据。导入文件应放在个人数据目录，不纳入源码。

`个人办公台.exe --export-all 输出.zip` 与界面的全部导出使用同一实现。导出不受当前搜索筛选影响。数据库通过 SQLite Backup API 生成一致性快照，未能读取的文档和旧库会在导出清单中注明，旧版无法生成快照时原样保留。未完成的导出不会替换已有文件。

标签随账号和物品记录导出，`自定义标签.json` 另存对应模块的完整标签目录，包括尚未分配的标签。旧数据首次打开自动补充空标签，不修改已有账号、密码或物品字段。拖入支持本机实际文件和文件夹，不接收浏览器文字或尚未落盘的附件；包含符号链接或联接的项目会报告失败。

## 联系人与聊天记录

在左侧“联系人”页点击顶部添加按钮或末尾方块，填写资料。只有姓名必填，手机号和身份证号按文本原样保存，性别可自行填写。

在详情中点击“导入聊天记录”，可多选 TXT、Markdown、JSON、Excel（.xlsx / .xls）文件。导入完成后点击“保存联系人”，资料和原文件一起存入本机数据库；同格式、同内容的文件跳过。查看记录可选择和复制文字，Excel 可切换工作表并滚动查看单元格，长单元格悬停显示全文。“聊天笔记”可直接填写交流摘要。关闭未保存的表单会放弃本次编辑。

文本接受 UTF-8 或带 BOM 的 UTF-16；JSON 保留任意原始字段，不要求特定聊天软件的数据结构；Excel 不要求固定列名，不执行宏，按单元格内容展示。每份文件最多 8 MiB，每位联系人的原文件总量最多 32 MiB；Excel 解压内容最多 64 MiB、总计 100,000 个单元格、每表 256 列，超出时提示拆分，不截断保存。当前仅导入已在本机的导出文件，不直接连接聊天软件。

顶部搜索同时匹配联系人资料、聊天笔记、记录名称和解析后的聊天内容。详情中的聊天记录可单独导出原件；页面顶部可导出全部联系人，或全部办公台数据。ZIP 中“联系人.json”保存资料、笔记、聊天文本和 Excel 单元格，每份聊天记录的 archive_path 指向 contact_chats 中的原文件，Excel 原件按原字节保留。删除联系人只删除办公台内该联系人的记录，不删除导入源文件。

新增验证包含联系人字段和附件重启后恢复、姓名与聊天内容搜索、重复导入、导入中禁止保存、关闭或切换联系人后不串入记录、数据库写入失败回滚、删除附件和级联删除联系人、UTF-16 文本、任意 JSON、多工作表 Excel、单独与整模块导出的原件一致性，以及联系人详情和聊天预览随窗口调整后居中。


## 宫格与条形列表

每页内容区右上方提供“宫格 / 列表”，点击立即切换。每个功能分别记住选择，重启后恢复。快捷路径（含文件夹内容）默认使用列表，其他功能默认宫格。

列表以整行展示内容；文件使用更紧凑的行高，按名称、类型、大小、修改时间对齐，长名称省略后可悬停查看全文。账号和物品的标签在列表中继续展示。两种视图共享搜索、筛选和右键菜单；文档仍在台内编辑，文件仍单击选中、双击使用系统程序打开；外部拖入复制同样支持两种视图。

视图设置保存在原有 settings 表的 view.* 键中，全部导出会包含设置。视图切换只影响展示，不移动文件、不改变记录或标签。不同功能和视图分别保存本次运行中的滚动位置。


## 账号直显、物品分类与小游戏

账号页面的宫格和列表直接显示账号、密码明文，不用打开详情；长内容换行完整显示。右键提供复制账号、复制密码，详情仍可编辑。

物品只使用统一的分类标签。详情中选择后保存，或右键“设置分类”保存，卡片标签、摘要、列表和顶部筛选会同步；清空后进入未分类。旧版自由填写的分类会保留为分类标签，重命名、删除也会同步；删除分类不删除物品。第一次升级只做一次兼容转换，清空的分类不会被旧值恢复。

文件右键增加“用默认程序打开”和“选择程序打开…”，后者调用 Windows 系统的打开方式。文件夹内容、文件快捷入口、文件搜索结果及已保存文档均支持；文档原有单击台内编辑和文件双击默认打开继续保留。

左侧“小游戏”中可选择无尽贪吃蛇，支持宫格或列表入口。方向键或 WASD 转向，空格开始/暂停/继续，Esc 暂停；支持重新开始。边缘穿墙循环，不设关卡和倒计时，撞到自己结束；吃到食物加 10 分，填满棋盘结束本局。切换页面、离开窗口、搜索框输入或打开对话框时自动暂停。最高分保存在本机，模块和全部导出包含“小游戏.json”。

## 便捷复制、小工具、Codex 与主题

账号宫格和列表的账号、密码旁均有“复制”按钮，点击即复制完整内容，显示“已复制”；无需进入详情。账号详情也保留复制按钮。网站宫格和列表新增“打开”按钮，直接在默认浏览器访问。

左侧“小工具”保存本机 EXE 的名称、路径和备注，支持搜索、宫格/列表、右键编辑与移除。双击条目直接启动程序；移除入口保留原 EXE。程序以自身所在目录为工作目录启动，工具导出只包含入口信息。

左侧“Codex”默认承载本机原版 Codex / ChatGPT 窗口。原版应用保持运行时，进入此页会自动嵌入唯一的主窗口；有多个窗口时选择后点击“嵌入现有窗口”。原来的项目、历史对话、ChatGPT Work、登录和其他原版入口由该窗口直接提供。也可点击“启动原版应用”从已安装的 Windows 应用启动，再刷新。切换办公台功能、点击“恢复独立窗口”或正常退出办公台时，会还原原窗口；不结束它的进程。

“基础聊天”按钮保留上一版 app-server 聊天作为备用。先选择项目文件夹，再点击“连接本机 Codex”，选择返回的模型后发送消息；Ctrl+Enter 发送，可查看流式回复、执行记录、停止任务、新建对话及恢复办公台里的历史对话。已有本机 Codex 登录会被复用；需要时点击“登录 Codex”，再打开浏览器完成登录。连接设置可手动选择本机 codex.exe。需要已安装、支持 app-server 的 Codex CLI；联网和模型可用性取决于本机 Codex 配置。聊天正文按可选择、可复制的文字展示。

备用聊天界面基于官方 [Codex app-server](https://developers.openai.com/codex/app-server) 构建，属于办公台自己的聊天界面。项目读写与命令执行遵循本机 Codex 配置；Codex 发出的命令及文件变更确认会在窗口中央显示。本机 Codex 的登录文件不复制到办公台，也不加入导出。办公台生成的对话副本保存在数据目录 codex 下，模块及全部导出会包含这些记录和连接设置。

在“设置 → 编辑主题”调整主题色、文字、页面、侧栏、卡片、输入框、边框与按钮颜色，也可调整缩放和透明度。支持上传 PNG、JPEG、WebP、BMP 背景，选择铺满裁切、完整显示或拉伸；图片最多 20 MiB、8192×8192，预览会缩小至最长边 2048。修改实时预览，点击“保存主题”才保留；关闭编辑器或按 Esc 放弃未保存修改。图片保存为办公台内的独立副本，移动原图片不会影响主题。主题可单独导出，全部导出同样包含配置与图片。

## 程序内更新（v0.2.0）

左侧“更新 v0.2.0”打开居中更新窗口，可检查更新、选择更新清单、安装并重启。默认读取程序旁 `updates/latest.json`；这是本机发布目录，目前没有配置网络更新服务。保留整个 dist 目录，后续开发端发布新版后，使用端直接点“检查更新 → 安装更新并重启”，无需安装 Rust 或手工替换 EXE。

开发端每次发布先提高 Cargo.toml 的版本号，再执行构建脚本。构建会自动生成 `dist/updates/<版本>/PersonalDesk.exe` 和版本/文件大小/SHA-256 清单，最后替换 latest.json。也可用 `scripts/publish-update.ps1 -Executable <已编译程序>` 发布已有构建；发布端仍需先编译 Rust 新代码，不提供运行中替换机器码。

安装先校验程序并备份 desk.db，未保存的账号修改或正在运行的操作会阻止重启。独立安装进程等待当前程序退出，再替换正在使用的同一 EXE，并保留 previous.exe。原个人数据目录及路径配置不被更新包覆盖。替换失败保留原版，启动失败会尝试还原并重启原版，错误写入安装目录日志并在更新窗口显示。
