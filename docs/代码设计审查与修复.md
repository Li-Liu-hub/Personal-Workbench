| 删除图书后，按页面 ID 仍能读取和写入其中内容 | 页面查询和保存均校验图书有效状态，新建文档也校验目标图书 | `db::audit_tests::deleted_books_hide_pages_and_reject_new_or_stale_writes` |
| 删除再恢复页面/图书没有使旧编辑器失效 | 实际删除状态发生改变时递增页面修订号；重复状态操作不递增；禁止删除内部文档根目录 | 删除恢复后旧版本保存返回冲突，原内容保留 |
