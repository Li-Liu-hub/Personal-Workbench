# 百科：408 与 MySQL 原理扩充

新增 **120 个知识点 + 120 道关联推演练习**。这是本科核心原理学习包，覆盖下列主题；不代表逐项覆盖某一年度官方考试大纲，也不是真题集。

## 使用

使用包含本次内容的新版程序，首次打开会自动增量导入。

- 百科顶部“全部领域”选择 **408**，分类选择数据结构、计算机组成原理、操作系统或计算机网络。
- 选择 **MySQL**，搜索 `MVCC`、`多版本`、`Read View`、`undo`、`快照读`、`锁定读`。
- 进入条目可查看例子、适用条件、自检和参考结论，并通过关联练习提交作答。
- 408 条目支持搜索、收藏、编辑及随百科导出；与原有编程语言资料使用相同机制。

## 重要边界

- 所有计算例子明确模型或假设；流水线、窗口、缓存、地址空间等参数不是所有真实机器的默认配置。
- 网络协议条目保留经典教学模型，同时指出 HTTP/3、IPv6、全双工以太网等不能套旧结论的情形。
- MySQL 以 **8.4 / InnoDB** 为前提。普通一致性读、锁定读和修改语句分开讨论；RR 不等于所有读取都固定在 BEGIN 时刻。
- `MVCC 双会话复现实验` 给出初始化、A/B 两连接执行顺序和预期结果。它需要真实 MySQL 与独立测试库，未配置为 SQLite 自动执行题。文中预期结果不冒充真实 MySQL 运行记录。
- 参考入口为 MySQL 官方手册/源码、MIT 课程、OSTEP 和 RFC，各条目保存对应链接；讲解和练习为本项目编写。
