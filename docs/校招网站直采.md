# 校招网站直采

入口：求职 → 校招搜索 → 网站直采。默认采集全部方向，入库后通过关键词筛选；取消“采集全部方向”可按岗位关键词限制入库。

内置信息源为 SMA 公开校招目录、秋招网公开目录、华中科技大学就业网、厦门大学嘉庚学院就业网、超级简历校招公告和国家大学生就业服务平台。支持补充最多 5 个公开列表或公告地址；通过页面中的招聘详情和下一页链接继续发现。

“每站列表页数”限制每个站点的列表页，“本轮页面上限”限制整轮任务，“详情页上限”限制进一步访问的企业与公告页面。采集串行执行，同一站点两次联网请求间隔至少 800 毫秒；读取超时为 12 秒，单页上限 4 MB。停止后已入库数据保留。

响应缓存位于数据目录 campus-crawler/checkpoint.sqlite，24 小时内复用；再次启动会重建待处理列表并重新保存缓存页中的结果，因此不会因停止时未保存某批结果而跳过它。缓存七天后自动清理，不是独立的投递记录库。岗位仍保存在 desk.db，真实投递记录仍来自 hiring/hiring.sqlite。

robots.txt 不允许访问的地址会跳过，读取 robots.txt 失败时也会记录原因；404 视为未声明限制。登录、会员按钮不作为投递地址。动态招聘系统或需要验证的网站可能只能得到入口；页面显示的投递入口来自公开信息，提交前请核对原文。整批公告只计一条，不把岗位方向拆成虚构的具体职位。

命令行可由同一程序 --campus-search [绝对数据目录] [条件.json] [报告.json] 调用。新增条件为 crawl、crawl_all、crawl_pages、crawl_details；原有条件兼容。网页内容只作为数据，不执行页面中的脚本或指令。本工具不会提交投递。
