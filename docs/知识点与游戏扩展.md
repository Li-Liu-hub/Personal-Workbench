# 知识点、练习与游戏扩展

## 使用目标

百科全书承担“查阅 → 理解 → 针对性练习”的闭环。语言目录负责组织，不用关键词猜测题目归属。推荐训练保持工程主线，知识点专项用于补齐具体缺口；自由混合与类别选题可包含专项题。

当前有 358 个知识点、400 道关联练习，加上原工程主线 70 题，共 470 题。JavaScript 63、Java 40、C 36、C++ 40、Rust 40、Go 40、Linux 43、MySQL 56。v0.13 增加 24 道具体任务，接受多种正确边界解释；仅对指纹匹配的旧内置评分点更新，不覆盖用户修改及历史快照。后续按学习缺口继续拆分、补充和校对，不声称覆盖全部语言标准。

## 内容约定

- `assets/reference.json` 保存知识点。稳定 `id` 不因改名而改变；每条有语言、分类、类型、标签、概要、语法、示例、边界与官方资料链接。
- `assets/reference_practice.json` 保存题目。`knowledge_ids` 为显式多对多关联，`tags` 描述语言、类别和形式，如代码阅读、边界辨析、SQL 实操。评分点合计 100 分。
- 构造函数原型对象、实例原型、原型链、自有属性遮蔽分别查阅；对象、数组、参数解构和 rest/展开分别组织。
- 窗口函数按排名、分布、偏移、取值、聚合、窗口帧分类，注明并列值、稳定排序、NULL、默认帧和版本限制。18 个 SQL 实操提供建表及含并列值的销售样例，在独立 SQLite 内存库执行兼容语法后回滚。
- 片段注明上下文与版本；不把未执行代码标成已验证，不把其他数据库的专有语法当作 MySQL 功能。Linux 练习不执行个人机器命令。

## 持久化与检索

`command_entries` 增量加入 `entry_type`、`tags_json`，标签进入 FTS5 trigram。语言、分类、类型和单个标签精确筛选，多个搜索词取交集，短词按字面量查找。目录只加载摘要，选中才读正文，仅绘制可见行。

导入使用版本标记与稳定 ID。只为未编辑的旧内置条目补元数据，不覆盖个人修订，墓碑不会复活。指令与题库分别事务提交，完成题库导入才写入完成标记，中断后可重放。

`study_knowledge(card_id, knowledge_id)` 是关联索引。仅给实际新增题目写入关联，同 ID 已存在的个人题不会被内置题覆盖。旧题/旧成绩缺少新字段时仍可读取，历史快照不回写。

专项先按知识点 ID 过滤，再应用掌握、近期避重复规则。空结果不能回退到无关工程题。跳转前保存待完成答案，后台批改或 SQL 执行中不替换上下文；专项记录本也按同一知识点筛选。

## 游戏与记录

- `games.rs`：贪吃蛇规则。0 为无尽模式，1–12 为关卡；目标和速度递增，逐步加入墙和障碍，通关后停止。
- `games/tetris.rs`：七袋洗牌、预览、每次落定前最多暂存一次、简化旋转避让、软降/硬降、消行计分和关卡目标。简化旋转不宣称完整 SRS 兼容。
- `games/records.rs`：版本化棋盘和最近缓存，保存随机状态、排队输入、方块袋、暂存、关卡和成绩。恢复时暂停并验证结构，无效存档不覆盖。
- `db/games.rs`：棋盘存设置，完成局写独立 `game_runs` 表，run ID 去重。缓存最近 100 局，旧局继续保留在表中，可加载与完整导出；逐关最好成绩单独保留。
- `app/game_ui/`：画板、关卡目录和交互分开。运行中定期检查点，得分、暂停、完成、切页和正常退出保存；强制结束进程可能退回最后一次成功检查点。

## 发布

本地完成检查、正式构建、旧数据副本验证，再用 `scripts/package-release.ps1` 生成免安装文件与校验清单。`packaging/windows/setup.iss` 使用 Inno Setup 6 构建安装版，普通客户端不依赖该工具。

GitHub 工作流 `Package tested Windows release` 接收已有草稿 Release 的版本标签，下载已测试 EXE 并核对哈希，再打包、验证独立目录安装/重复安装、载荷一致、卸载保留数据，最后附加安装版、ZIP 和清单。

安装包不含数据库、文档或模型。已有数据指针优先保留，程序路径与数据路径独立，卸载不递归删除数据目录；不自动关闭运行中的个人办公台。
