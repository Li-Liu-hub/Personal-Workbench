# 百科：408 学科拆分与更多语言扩充

本轮两项改动：把 **408 由单个聚合包拆成四个独立学科包**，并新增 **TypeScript / PHP / Kotlin / C# / Lua 五个语言专题包（60 个知识点 + 60 道练习）**。内容来源为各语言官方文档，讲解与练习为本项目原创编写。

## 408 拆分

原 `cs408` 聚合包（96 条，language=408）按学科拆分为四个独立包，每个 24 条知识点 + 24 道练习：

| 学科 | 资产 | 导入标记 |
| --- | --- | --- |
| 数据结构 | `assets/data_structures.json` / `_practice.json` | `encyclopedia.data_structures.version` |
| 计算机组成原理 | `assets/computer_organization.json` / `_practice.json` | `encyclopedia.computer_organization.version` |
| 操作系统 | `assets/operating_systems.json` / `_practice.json` | `encyclopedia.operating_systems.version` |
| 计算机网络 | `assets/computer_networks.json` / `_practice.json` | `encyclopedia.computer_networks.version` |

- 条目的 `language` 改为学科名，顶部“全部领域”下拉分别出现四个学科，分类仍是学科名。
- **条目 ID 与练习 ID 保持不变**，已有收藏、编辑、删除墓碑与作答历史全部对应。
- 旧安装升级时，`encyclopedia.cs408.subjects.version` 标记下的迁移只把 96 条旧记录的 `language` 从 408 改为所属学科（并重建搜索文本），不改内容、不改编辑。
- “考研408”标签保留，可按标签筛选整套学科内容。

## 数量与验证

- 百科内置总量由 **841 增至 901**（408 拆分不改变总数，更多语言 +60）。
- 内置工程题由 **965 增至 1025**（更多语言 +60；408 拆分不改变总数）。
- 回归测试覆盖：四个学科的语言/分类筛选、练习精确关联、旧 408 记录迁移后的编辑与收藏保留、更多语言包的搜索与关联、导出包含全部学科与语言条目。

## 维护

- 408 四个学科包由 `scripts/encyclopedia-extras/build.py` 的 `split_cs408()` 从 `assets/cs408.json`（`scripts/build-cs408-catalog.py` 生成）拆分产出；原聚合资产保留为上游源数据，不再被程序导入。
- 更多语言内容在 `scripts/encyclopedia-extras/more_languages.py`，运行构建脚本仅重建资产，不写用户数据库。
