# Excel 批量合并工具

> 此目录保留历史工具源码作为参考。当前 Excel 合并功能已内置到个人办公台“小工具”，统一从 `dist/个人办公台.exe` 使用和更新；不再在项目内分发独立 `excel-merge.exe`。下文为历史工具说明。

选择一个文件夹，把它里面**所有 Excel 的全部 sheet 流式合并成一个 Excel**。
纯图形界面，双击 `excel-merge.exe` 即可使用。

- **遍历每个文件里的所有 sheet**（不再是只取第一个），所有 sheet 的数据打平汇入同一组输出 sheet
- 顺序：按文件顺序，文件内按 sheet 顺序（文件1的sheet1→sheet2→…，再文件2的sheet1→…）
- 支持读取：`.xlsx` `.xlsm` `.xls` `.xlsb` `.ods`

---

## 一、怎么用

双击 `excel-merge.exe`，窗口里三步：

1. **源文件夹** — 点「浏览…」选中存放待合并 Excel 的文件夹
2. **输出文件** — 点「另存为…」指定合并结果保存到哪里
3. **每个 sheet 放多少条数据** — 见下面第二节，有滑杆、数字框和常用档位
4. 点 **开始合并**

底部有进度条和实时日志，完成后可一键「打开文件」。

---

## 二、调整「每个 sheet 放多少条」

界面上有三种方式，随便用哪种，三者会自动同步：

| 方式 | 说明 |
|---|---|
| **数字输入框** | 直接手打精确数值，如 `30000` |
| **滑杆** | 拖动调整，范围 1 千 ~ 104 万，对数刻度（小数区更精细） |
| **常用档位按钮** | `5千` `1万` `5万` `10万` `50万`，一键切换；`不分片` = 全部塞进一个 sheet |

- 默认值：**5 万条 / sheet**
- 硬上限：**1,048,575 条 / sheet**（Excel 单表最多 1,048,576 行，扣掉表头行）
- 数字框旁边会实时显示易读换算，如 `≈ 5万`
- 输入非法（0、超上限、非数字）时，开始合并会提示错误，不会带着错值跑

> 分片规则：每累计到设定条数就新开一个 sheet，命名 `数据1`、`数据2`……
> 最后一个 sheet 装剩下的。**表头只在整份结果的开头写一次**，
> 后续 sheet 从第一行开始就是数据，不重写表头（想每个 sheet 都带表头见下）。

怎么选合适的值？百万行级建议 `5万` 左右——既能避开 Excel 上限，文件保存和打开也快。

## 二之二、两个表头开关

界面上有两个复选框，按需勾选：

| 复选框 | 不勾（默认） | 勾选 |
|---|---|---|
| **每个 sheet 都带表头** | 表头只在整份结果的最开头出现**一次** | 每新建一个**输出** sheet，第 1 行都**重写一遍表头** |
| **移除子文件的表头** | 各子文件、各 sheet 自己的表头行**原样当数据写入**（纯暴力合并） | 它们自己的表头行被**跳过，不进入结果** |

两个开关互相独立，可以任意组合：

| 组合 | 结果 |
|---|---|
| 都不勾 | 表头只在最开头一次；子文件/子 sheet 的表头行混在数据里 |
| 只勾「每个 sheet 都带表头」 | 每个输出 sheet 第 1 行都是表头；子表头行仍在数据里 |
| 只勾「移除子文件的表头」 | 表头只在最开头一次；子表头行被剔除，数据更干净 |
| 都勾 | 每个输出 sheet 第 1 行都是表头；子表头行被剔除（**推荐**，最干净） |

> 注意：**第一个文件的第一个 sheet 的第一行**无论如何都会被取出来当基准表头，
> 「移除子文件表头」只作用在**其余 sheet**（含第一个文件的其余 sheet）的第一行。

## 二之三、多 sheet 合并规则

不是"只取每个文件的第一个 sheet"，而是**遍历全部**：

```
file1.xlsx                 file2.xlsx
 ├─ sheet1  表头+数据  ┐    ├─ sheet1  表头+数据  ┐
 ├─ sheet2  表头+数据  ├─→  ├─ sheet2  表头+数据  ├─→  数据1 / 数据2 / …
 └─ sheet3  表头+数据  ┘    └─ sheet3  表头+数据  ┘
```

- **打平**：所有 sheet 的数据被视为同一个表结构，汇入同一组输出 sheet
- **顺序**：文件1的 sheet1→sheet2→sheet3，然后文件2的 sheet1→…（按文件分组，文件内按 sheet 顺序）
- **列数校验逐个做**：每个 sheet 检查自己的第一个有效数据行；列数不符会报错并
  指明**是哪个文件的哪个 sheet**
- **空 sheet**：跳过（不会报错）

> 若某个文件里的多个 sheet 其实是**不同的表结构**（比如一个是订单、一个是客户），
> 就不适合用本工具 —— 它的前提是「这批 sheet 结构一致」。

## 三、它是怎么做的（流式读写）

**流式读 + 流式写 + 逐 sheet 流水线**，不是「先全部读进内存、最后一次性写出」。

```
扫描文件夹
   ↓
┌─ 文件1 ─┬─ sheet1 → 边读边写 → 释放 ─┐
│         ├─ sheet2 → 边读边写 → 释放  │  峰值内存
│         └─ sheet3 → 边读边写 → 释放  │  ≈ 单个最大 sheet
│  文件2 ─┬─ sheet1 → 边读边写 → 释放  │
│         └─ ...                       │
└─ 文件N ─┴─ ...                       ─┘
   ↓
保存
```

具体实现：

- **读** — calamine 的迭代式接口逐行取单元格，不整表载入
- **写** — rust_xlsxwriter 的 `constant_memory` 模式，行写下去即落盘，不在内存里囤
- **流水线** — 每个 sheet 处理完立刻 `drop(book)`，内存占用与**文件总数、sheet 总数无关**

**实测对比**（81 个文件、158 万行、318 个 sheet）：

| 指标 | 流式版 | 旧的全量缓冲版 |
|---|---|---|
| 峰值内存 | **118 MB** | 数 GB |
| 耗时 | **78.8 秒** | 100 秒 |

所以文件越多，这个设计的优势越明显。

## 四、合并规则（刻意保持简单，不做纠错）

按你的要求，格式默认一致，工具不猜、不纠正：

- **表头**：只取**第一个文件的第一个 sheet 的第一行**作为基准表头，在结果最开头写**唯一一次**
- **数据**：所有文件的**所有 sheet** 的数据行，按「文件顺序 → sheet 顺序」依次追加
- **每个 sheet 带表头**（可选）：勾选后每个**输出** sheet 的第 1 行都重写一遍表头；不勾则新开的 sheet 不写表头
- **移除子文件表头**（可选）：勾选后跳过各子文件、各 sheet 自己的表头行；不勾则当普通数据原样写入
- **列数不一致**：**直接报错停止**，并在日志里指明是哪个文件、哪个 sheet、第几行、基准几列它几列
  （不做列名匹配、不做自动对齐——格式不一致就说明这批文件选错了）
- **空行**：整行无内容的跳过；**空 sheet** 同样跳过
- **数字**：自动识别为数值类型（方便求和排序）；前导 0 的编码如 `007` 保持文本
- **临时文件**：`~$` 开头的 Excel 临时文件自动忽略

**行数口径**（`sheet` = 所有文件的 sheet 总数）：

```
数据行数 = Σ(各 sheet 原始行数) − 1        （不勾「移除子文件表头」）
数据行数 = Σ(各 sheet 原始行数) − sheet数   （勾选「移除子文件表头」）
```

减 1 是因为第一个 sheet 的第一行被取出来当基准表头了。
勾选「移除子文件表头」后，每个 sheet 都要再减掉它自己的表头行，所以减去 sheet 总数。

## 五、代码结构

```
excel-merge-tool/
├── excel-merge.exe   可直接运行的程序（已内嵌图标，双击即用）
├── src/
│   ├── main.rs       入口（双击即开 GUI）
│   ├── merge.rs      核心：流式读 + 流式写 + 分 sheet
│   └── gui.rs        图形界面
└── README.md         本文件
```

> 本目录只保留「可执行文件 + 源码 + 说明」。
> `Cargo.toml`、`build.rs`、`build.bat`、`assets/` 与编译缓存 `target/` 已清理。
> 如需重新编译，按下节重建这些文件即可。

原依赖：`calamine`（读）、`rust_xlsxwriter`（写，启用 `constant_memory`）、
`eframe`+`egui`（界面）、`rfd`（原生文件夹对话框）、`chrono`（时间戳）、
`image`（解码窗口图标）、`winresource`（编译期嵌入 exe 图标）。

## 六、自己编译

项目清理时已删除编译配置，重新编译需要先补回：

**1. `Cargo.toml`**

```toml
[package]
name = "excel-merge-tool"
version = "0.2.0"
edition = "2021"

[[bin]]
name = "excel-merge"
path = "src/main.rs"

[dependencies]
calamine = "0.26"
rust_xlsxwriter = { version = "0.79", features = ["constant_memory"] }
eframe = { version = "0.29", default-features = false, features = ["default_fonts", "glow", "wayland", "x11"] }
egui = "0.29"
rfd = "0.15"
chrono = "0.4"
image = { version = "0.25", default-features = false, features = ["png"] }

[build-dependencies]
winresource = "0.1"

[profile.release]
opt-level = 3
lto = true
codegen-units = 1
strip = true
```

**2. `assets/icon.png` 与 `assets/icon.ico`**（256×256 以上，ico 需含多尺寸）
—— 任意图标即可；缺了也能编译，只是 exe 与窗口没有头像。

**3. `build.rs`**（把 ico 嵌进 exe）。本机有个坑：`winresource` 默认靠
`reg.exe` 查 Windows SDK 路径，而本机安全策略把 `reg.exe` 拉黑了，
会报「系统找不到指定的路径 (os error 3)」。所以 build.rs 里要手工扫
`C:\Program Files (x86)\Windows Kits\10\bin\*\x64` 找到 `rc.exe`，
再用 `res.set_toolkit_path(...)` 告诉它。

然后：

```bat
set PATH=%USERPROFILE%\.cargo\bin;%PATH%
cargo build --release
```

产物 `target\release\excel-merge.exe`，单文件，无外部依赖，可直接拷给别人用。

## 七、使用提示

- **合并前把 Excel 关掉**，文件被占用会读取失败并报错
- 输出文件已存在会直接覆盖
- 支持读取：`.xlsx` `.xlsm` `.xls` `.xlsb` `.ods`；**每个文件的全部 sheet 都会被遍历**
- 输出格式：`.xlsx`
- exe 已内嵌多尺寸图标（16/24/32/48/64/128/256），资源管理器与任务栏都会显示
