# 学习训练与评分约定

目标是逐步形成可迁移的工程能力和英语表达能力。八股、SQL、Linux 是入口；题目形式按学习目标选择，不能用几套题干替换关键词冒充完整训练体系。

## 内容分层

| 层次 | 工程训练 | 英语训练 |
| --- | --- | --- |
| 知识结构 | 编程、Java/并发、数据库、系统/Linux、网络/Web、可靠性、测试排障、性能交付 | 词义、搭配、语法、句子表达、翻译、阅读理解 |
| 任务形式 | 解释、结果推演、补全、修复、代码审查、方案选择、排障验证、项目实战 | 释义、造句、双向翻译、改错、填空、比较辨析、改写、合句、短文问答 |
| 评价依据 | 对应知识点、具体要求、可观察结果、合理边界；SQL/项目有独立执行证据 | 语义、语法、用词、表达；按题目要求接受合理替代答案 |
| 复习记录 | 题目稳定编号、实际作答、评分点、辅助标记、连续达标 | 生成变式保留原题；单词×练习方式汇总独立达标，不等于已掌握全部英语知识 |

百科全书是可编辑的知识资料库，每条可以跳到精确关联的练习；不是用标题相似度猜测知识点。通用知识点题用于解释与边界练习，具体变式提供真实代码、输入或场景。新增题目应明确产出，不为没要求的内容扣分。

## 小模型评分

`local_ai::grade_request` 提供题目、练习方式、参考、各评分点、学生原文及真实执行报告。本地模型按顺序返回评分点编号、原文依据、已答对的事实 `c_matched` 和仍缺失/错误的要求 `d_missing`。两类事实分开保存到展示理由，避免先拍分数再编理由；只提到相关关键词不构成已答对。

- 有已答对事实，且没有明确缺口：换算该项满分。
- 有已答对事实，也有明确缺口：换算一半，奇数分向上取整。
- 没有已答对事实：未覆盖或错误，换算零分。

判分遵循语义：列表 `A,B` 与 `[A, B]` 的格式差别不能被当作知识错误。只要求结论的一项，结论正确即可；要求结论和原因时，只给结论得部分分，不能脑补原因。自由造句没有唯一参考句；英译中只需翻译原文，原文是问句时不要求回答该问题。

Rust 校验评分点数量、编号唯一、分值范围及非零项的真实原文依据，再加总；初评零分独立重评一次，确实无关或全错仍可为零。格式或依据校验失败不计成绩，保留答案待重试。`Assessment` 保存协议版本与是否复核，模型名称和时间保存在原有 Attempt 中；老版本没有元数据仍可读取。

4B 量化模型的判断仍可能不准确，参考解答也可能有错误。模型点评不能代替程序实际运行或人工核对；SQLite 样例通过也不等于覆盖全部边界。复制结果应同时带上原题、学生原文与反馈，便于外部复核。升级不重写历史成绩。

## 英语变式

基础语法使用 `assets/english_grammar.json` 中本地编写的 24 个重点、48 道任务，包含正确参考与具体讲解，不依赖模型即时出题。编号 `english:grammar:v3:{知识点}:{变式}` 稳定，按语法知识点汇总连续达标并执行停止/低频复习规则。旧单词语法题与历史仍保留，不冒充新语法任务，也不把练语法计为掌握某个随机单词。

`english::planning` 将词条与题目计划分离：每种方式持久保存递增序号，轮换表达目标、适配形式、8 种主题语境及 B1/B2 难度。造句在本地生成要求；翻译、搭配、改写和阅读由模型按计划生成。

生成题目使用新编号 `drill:{方式}:v2:{序号}:{词条}`，保存目标词 origin、题目标签、题干、参考和讲解；旧 `drill:{方式}:{词条}` 保留。生成成功且保存后才推进计划，失败重试同一计划；改错题的原句与参考句相同则拒绝并自动重试一次；历史和待完成题始终使用保存的内容，不在查看时重新生成。生成题干不保证都是唯一解，不能声称模型自动生成等同于经过人工审定。

独立作答按单词及练习方式合并不同变式的连续分数，基础语法按知识点合并；辅助答题不计连续掌握。每日统计为不同单词或语法知识点，单题记录仍各自保留。更换句子不会把学习进度清空；两道基础任务达标也不代表掌握该语法的所有复杂用法。

语法分类参考 [British Council B1–B2 grammar](https://learnenglish.britishcouncil.org/free-resources/grammar/b1-b2) 的常见主题，题干由本项目或本地模型编写。分类不作为雅思官方评分标准。

## 模型生命周期

只管理本客户端启动的子进程，不扫描并停止其他程序的模型。首次请求加载权重；后续题目、翻译和讲解复用同一端口及进程。健康检查与处理新上下文不是重新加载权重。

学习页面可长时间读题和思考，不触发空闲卸载。离开刷题王/每日单词后，空闲计时开始；设置 0 表示只手动停止。生成中取消通过流取消检查结束当前请求并关闭响应，不清除权重；需要释放显存时使用停止模型。退出和崩溃通过子进程所有权回收推理进程。

## 升级和验收

新版通用知识点评分仅在旧卡片的规范化 JSON SHA256 与旧内置指纹完全一致时更新；修改过的题目不覆盖。24 道新具体变式使用新编号，导入及版本标记可重放。历史 Attempt 的题目与反馈快照保持原值。

验收同时包含：等价格式的部分正确回答、完整回答、明确错误/无关回答；翻译与自由表达；实际生成的多种形式；同进程复用、学习期间不卸载、离开后卸载、取消生成不丢答案；旧题、自定义题、历史快照及导出兼容。实模测试显式运行，不计作普通自动回归。
