# 校招搜索

在“小工具”中打开“校招搜索”。默认关键词 Java、2027 届，城市留空表示全国。多个关键词用空格或逗号分开，各自检索；只读取前四个关键词。

- 国家大学生就业服务平台：按关键词读取职位，搜索深度可设 1–10 页，每页最多 20 条；读取每页前 3 条详情补充正文。平台也有非校招职位，届别未注明的结果保留并提示核对。
- 校招公告：读取超级简历的公开搜索页，每个关键词读取当前页最多 12 条公告及其公开详情。不尝试读取登录后才能查看的投递地址。
- 全网发现：读取 Bing 公开搜索结果，并尝试读取招聘原文和公告链接；最多搜索前两个关键词。遇到验证页、限制或超时会报告状态。搜索摘要只能作为待核验线索，不代表官方确认。
- 增强全网搜索（可选）：填写 Tavily API Key 后使用 Tavily 搜索服务，按账户额度计费。密钥仅在当前运行中保留，不保存到数据库、备份或 Excel；未提供密钥的真实服务调用尚未验收。
- 补充网址：每行一个公开公告或列表网址，每次最多 5 个。可识别结构化 JobPosting、常见公告正文和招聘链接。需要登录、脚本渲染、PDF/图片公告暂不支持。

结果保存到原数据目录的 desk.db，新增独立 campus_jobs 表，不修改既有业务记录。关闭面板后搜索继续；退出程序会请求停止，已保存结果保留。相同原文网址刷新时保留收藏、已投递、忽略和首次发现时间。不同岗位、城市、批次的网址保留；跨站转载不做模糊合并。

点击标题展开摘要。公告原文和投递链接分别展示；投递链接只表示原文明确提供的地址，需要本人核验。找不到投递链接时可“查找企业官网”。未注明的日期、届别和学历不补猜，访问失败不判定截止。

收藏、已投递、忽略、恢复均即时保存。本次结果和本次新增筛选只对当前搜索会话有效。列表本地筛选的多个词为同时匹配。隐藏已截止只隐藏明确注明且早于今天的截止日期。

“导出当前列表 Excel”导出当前可见结果及原文、投递地址。设置中的全部数据导出或小工具导出包含校招岗位与搜索条件；完整数据库快照保留这些记录。

界面、网络请求、解析、数据库和 Excel 导出均由 Rust 实现，不依赖 Python。HTTPS 启用证书验证；请求设 10 秒总超时及 4 MB 正文上限。停止后不再发起新请求，当前请求最多等待其超时；信息源可用性随网络、登录限制和页面结构变化，不保证覆盖全网。

默认只保留明确出现校招、应届、毕业生、实习或毕业届别的信息，避免社会招聘岗位混入。需要扩大范围可勾选“含未注明校招的岗位”。届别缺失仍会保留，并展示为未知，需核对原文。
