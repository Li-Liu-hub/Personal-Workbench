# PDF 转图片

在「小工具」中点击「PDF 转图片」，选择 PDF 和输出文件夹，然后开始转换。也可在搜索框输入 PDF、PNG 或 JPG 找到入口。

- PNG：无损，适合文字、表格、截图。
- JPG：支持 1–100 质量，适合需要较小文件的场景。
- WebP：无损，适合需要较小体积的清晰图片。
- BMP：兼容传统图片工具，文件通常较大。

清晰度为 72–600 DPI，默认 150 DPI，可快捷切换 96、150、300 DPI。清晰度决定图片的像素尺寸。JPG 为白底，PNG、WebP、BMP 也统一使用白底。

页码留空导出全部页面；输入 `1,3-5` 导出第 1、3、4、5 页。中文逗号也可使用。重复页码只导出一次，并按原页码升序保存。

每次都会在所选文件夹中新建独立结果文件夹，图片命名为 `原文件名_0001.png` 等。所有页面处理成功后才保存结果文件夹。失败或取消时清除本次临时结果，原 PDF 和已有图片保持不变。点击「打开结果文件夹」可查看图片。

关闭转换面板后任务继续运行，重新打开可查看进度。点击「取消转换」将在当前页面处理结束后停止。

使用 Windows 自带 PDF 引擎，全程本机处理，无需下载额外转换程序。需要密码的 PDF 请先解除打开密码，再进行转换。损坏文件会显示错误。为控制内存占用，单页最多约 6000 万像素，超大页面需要降低清晰度。

## 开发验证

转换服务位于 `src/pdf_images.rs`，界面位于 `src/app/pdf_images_ui.rs`。原生转换测试覆盖四种格式的文件签名、尺寸与像素、页码排序、取消清理、源文件保护和后台任务。

可选的可视化验收测试 `render_visual_acceptance_document` 需要设置 `PERSONAL_DESK_PDF_FIXTURE`（三页测试 PDF 路径）与 `PERSONAL_DESK_PDF_OUTPUT`（图片输出目录），并在同目录放置 `encrypted.pdf` 用于密码错误验证。它默认忽略，需显式运行；常规测试通过不代表运行了这项验收。

界面截图沿用现有预览流程，设置 `PERSONAL_DESK_PREVIEW_PDF_ONLY=1` 与 `PERSONAL_DESK_PREVIEW_OUTPUT` 后启动调试程序的 `--layout-preview`，可仅检查转换面板的两种窗口尺寸。预览使用临时数据，不作为日常入口。
