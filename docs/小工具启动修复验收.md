## 原因与修改

- 小工具入口原来仅检查 `double_clicked()`，单击不产生启动请求。宫格和列表均改为单击启动，双击的第二下不再次启动。
- `canonicalize()` 在 Windows 返回带 `\\?\` 前缀的路径。保存与启动前通过已有的 `files::shell_path` 转为普通路径，兼容旧数据库保存的入口；目标程序的工作目录仍为 EXE 所在文件夹。
- 成功创建进程后显示“已发送启动请求”，失败时显示具体错误。该提示表示进程创建成功，不保证目标程序后续不会自行退出。
- 保留右键启动、编辑、移除及收藏；不修改工具程序或迁移用户数据。
