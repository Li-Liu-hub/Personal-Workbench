# UI 与动效验收（0.15.48）

初始排查以本机 0.15.46 的程序和源码为起点，改动前构建产物与更新载荷 SHA-256 一致，源码备份位于项目外的 `个人办公台-发布归档/2026-11-02-v0.15.46-before-ui`。工作期间另一个发布任务发布了 0.15.47，本次最终发布基线采用正式标签 `v0.15.47`（`6a3e139`），在独立源码快照上整理本次修改并递增为 0.15.48，保留该正式版本的远端更新行为。没有重新接回已独立迁出的工具。

## 输入与视觉

- 列表空值的 `—` 仅在输入格没有焦点时绘制。先处理 TextEdit 的输入响应，再决定是否显示占位，避免点击第一帧仍有横线。
- 保留真实文本、首次全选、中文输入、删除、保存与取消。占位符不进入数据模型。
- 默认配色采用浅灰蓝背景、白色卡片与靛蓝强调色；统一导航、搜索、列表、按钮和弹窗的层次。
- 宫格宽度向下取整，避免最后一列因像素舍入提前换行。
- 仅刷新匹配旧默认配色的主题。用户颜色、背景路径、不透明度、缩放及动画开关继续保存。

## 动效

- 悬停、选中、按钮按压约 160 ms；页面与分段滑块约 180 ms。
- 动画只改变颜色、阴影、图标偏移或内容透明度，点击区域和列表几何保持固定。
- 动画结束后不持续请求逐帧重绘。关闭“启用界面动画”后立即显示最终状态。

## 自动验收入口

`scripts/verify.ps1 -TargetDir D:/codex-build/personaldesk-main` 执行格式、Clippy、Rust 回归与脚本测试。列表输入回归包含鼠标按下、中文输入、全选删除、失焦恢复和 Tab 进入；已有测试覆盖小窗口、显示缩放、长内容、弹窗、滚动虚拟化、写作草稿、更新和数据保留。

调试构建支持 `--capture-ui <输出目录>`：使用临时数据库和示例联系人、文档、物品、账号、网站及程序入口，自动生成 1000×680 与 1280×800 窗口截图后退出。截图直接来自实际 egui 渲染；不读取安装数据目录、不更改自启动设置、不进入正式发布包的运行入口。

拆分后遗留的学习配置测试改为检查未知设置原样保留，移除重复测试标记及未使用的辅助方法，并修正现有更新代码的 Clippy 格式问题。
