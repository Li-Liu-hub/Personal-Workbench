# 个人办公台图标 · 方案 1

设计：蓝青色圆角底板，白色书页与桌面组合，表达知识学习与日常办公。通过简洁轮廓保持小尺寸辨识度。

使用内置 image_gen 工具生成原图，以 Windows System.Drawing 导出尺寸和封装 ICO。原图保留不变。已将最终素材复制到 assets/personaldesk.png 和 assets/personaldesk.ico，供程序窗口、Windows 可执行文件和安装包使用。

## 文件

- personaldesk-master.png：1254 × 1254 原始透明 PNG。
- personaldesk.ico：含 16、24、32、48、64、128、256 像素，共 7 个尺寸。
- personaldesk-{尺寸}.png：各尺寸透明 PNG。
- size-preview.png：浅色背景下的实际尺寸预览。

验证：原图左上角 alpha 为 0；ICO 文件类型为图标，7 个尺寸的目录、数据范围及 PNG 签名均有效；已目视检查缩小效果。

## 最终生成提示词

Use case: logo-brand. Asset type: final Windows desktop application icon for a lightweight private personal productivity and learning workbench named PersonalDesk (个人办公台). Create ONE polished, distinctive app icon, square canvas 1024x1024. Subject: a beautifully simplified white open notebook / two knowledge cards resting above one short sturdy desk-like horizontal base, forming one coherent recognizable emblem. One broad cyan accent panel on the right card. Restrained deep azure to teal gradient rounded-square tile behind the white emblem, satin flat-vector-like finish with very subtle depth. Large simple geometry and bold white silhouette, balanced generous optical spacing. The tile fills approximately 88 percent of canvas, centered, smooth rounded corners, with real transparent pixels outside the tile. Main emblem must remain easily identifiable at 32x32 and 16x16. Design language: calm, precise, compact, professional modern Windows productivity tool. Front facing, straight-on, no perspective. Deliver the ACTUAL icon asset, no presentation board. No text, no letters, no numbers, no watermark, no mockups, no scenery, no circuit/chip motif, no decorative sparkle, no tiny UI lines, no fine details, no long cast shadow. Use real alpha transparency outside the rounded square, not a drawn checkerboard.

生成参数：transparent_background=true。实际生成尺寸以原始文件为准。
