# Obsidian 风格写作与博客发布

## 本地写作

“文档”和“图书”继续使用个人办公台现有的页面列表、图书目录和个人数据目录。正文编辑器提供 Obsidian Live Preview 风格的 Markdown 同屏编辑：编辑行显示 Markdown 标记，离开编辑行后收起常见标记并保留格式预览。支持原有标题、标签、自动保存、草稿恢复、版本记录、阅读预览和导出。

编辑器使用 MIT 许可的 CodeMirror 6 组件并随个人办公台程序离线提供，不需要安装额外的桌面程序；没有复制 Obsidian 的私有代码。文档仍保存在现有本地数据库，不会迁移或重置。构建编辑器资源使用 `scripts/build-markdown-editor.ps1`，离线资源包附带第三方许可文本。

## 发布到个人博客

1. 打开要发布的文档，确认标题、正文和标签。
2. 点击“发布到博客”。这会立即将当前内容公开到个人博客。
3. 程序使用本机 `~/.ssh/server_management_ed25519`（Windows 下 `%USERPROFILE%\.ssh\server_management_ed25519`）；如果该文件不存在，可以在文件选择框中指定 SSH 私钥。
4. 发布时直接 SSH 到博客服务器，在服务器上读取博客数据库配置并执行事务更新。不会调用博客 HTTPS API；数据库密码不会传回本机，也不会打包进程序。

首次发布会在个人办公台本地数据库中记录文档与博客文章编号的对应关系；之后再次发布同一文档会更新原文章，避免重复生成文章。文章标签同步更新。此映射随个人数据保留。

发布只写博客的文章与标签表，不修改本地文档以外的数据，也不部署或重启服务器服务。服务器连接地址、端口和数据库目标由程序固定为当前个人博客配置。

标题上限为 200 个字符、正文上限为 200 KB、标签最多 8 个且每个不超过 50 个字符。SSH 连接、服务器权限或数据库写入失败时，页面显示错误；如果服务器已完成写入但回执未到，再次发布仍会更新同一篇文章。
