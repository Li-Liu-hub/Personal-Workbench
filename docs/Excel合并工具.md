# Excel 合并工具

从“小工具”点击“Excel 批量合并”进入。该功能直接编译进个人办公台，不调用根目录的 `excel-merge-tool/excel-merge.exe`，也不需要安装 Excel。原工具目录保留作为来源参考。

## 使用与规则

1. 选择源文件夹，支持 `.xlsx`、`.xlsm`、`.xls`、`.xlsb`、`.ods`。默认只扫描当前文件夹，可勾选“包含子文件夹”；不跟随目录符号链接，扫描失败会明确报错。
2. 指定输出 `.xlsx` 文件。位于源文件夹中的同一路径输出和 `~$` 临时文件自动排除。已有输出需要在另存为对话框确认覆盖，或勾选“覆盖已有输出”。
3. 设置每个输出工作表的**数据条数**，范围 1～1,048,575，默认 50,000。表头不占此配额，结果按“数据1、数据2……”分表。
4. 按文件路径名称排序，文件内按原工作表顺序合并，首个非空工作表的首个非空行作为基准表头。空工作表、空行跳过；从 B/C 列开始的来源保留前面的空列位置。
5. “每个结果工作表都带表头”：关闭时只在结果开头写一次，开启时每个结果表均重复。默认关闭。
6. “移除其余来源工作表的表头”：关闭时后续来源的首个非空行保留为数据，开启时跳过。默认关闭。每个来源仍验证表头列数，按列位置追加，不自动匹配列名。
7. 数据行允许末尾字段留空；任何行出现超出表头范围的非空列，立即停止，并指出文件、工作表和原始行号。

请只选择列结构一致的数据表。不同业务表不应放在同一批次；本工具不猜测列名对应关系。

## 数据与运行边界

- 文本保持文本，包括前导零、超过 15 位的编号、看起来像数字或公式的字符串；数值与布尔值保持原类型。
- Excel 日期保留日期值，统一显示年月日和时分秒；持续时间使用累计小时格式。ISO 日期/持续时间文本保留文本。
- 合并单元格值，不复制原格式、图片、合并区域、宏或公式。公式读取文件内已缓存的结果，不执行重算；源文件缓存缺失或过期时，应先在原表格软件中重算并保存。
- calamine 每次读入一个工作表 Range；写出使用 constant-memory 模式。内存仍受单个工作表大小、工作簿元数据和输出工作表数量影响，没有承诺固定内存或逐行流式读取。
- 后台单任务运行，可关闭面板并继续使用其他页面，再次打开保留进度。运行中禁止再次启动同一功能；正常退出应用前需等待完成或取消。
- 取消在扫描、工作表之间和数据行之间检查；正在读取一个大工作表或打包保存时需等待当前调用返回。
- 结果先写到目标文件夹的临时文件，写入及同步成功且未取消后才原子替换目标；读取、校验、取消和保存失败会保留旧目标，临时文件自动清理。
- 面板参数和日志仅本次运行保存，最多保留 100 条日志。内置入口支持搜索、宫格/列表和收藏置顶，在“全部分类”或“未分类”下显示；原始 Excel 和结果属于用户选定的外部文件，不写入数据库或自动加入个人数据导出。

## 维护结构

| 文件 | 职责 |
| --- | --- |
| `src/excel_merge.rs` | 输入校验、扫描、合并编排、取消和原子提交 |
| `src/excel_merge/writer.rs` | 保持类型的单元格写入、精确分表、流式写出 |
| `src/app/excel_merge_ui.rs` | 原生面板、后台任务与有界进度通道 |
| `src/app/tool_ui.rs` | 内置入口、搜索、收藏和视图 |
| `src/excel_merge/tests.rs` | 真实工作簿读写回归 |
| `src/app/excel_merge_ui/tests.rs` | 入口点击、视图和后台状态回归 |

仅新增 `rust_xlsxwriter` 写出依赖，复用现有 calamine、eframe、rfd、tempfile、walkdir 和 chrono；不引入旧工具的第二套界面运行时。
