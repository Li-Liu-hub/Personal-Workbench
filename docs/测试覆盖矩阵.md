# 功能与测试覆盖矩阵

> 本表对应 0.15.76 的「根目录核心库 `personal-desk` + `desktop/` Tauri + React 客户端」结构。0.15.38 及更早版本记录中的原生 egui 界面、小游戏、刷题王、每日单词、百科全书、求职与学习工具已迁到 `D:\MyProject` 下的独立项目，相关旧条目不再属于本仓库的测试范围。

维护入口：`scripts/verify.ps1`。它依次执行根 crate 与 desktop 后端的 Rust 格式检查、Clippy（含 release 库）、Rust 回归、`desktop` 前端构建 / lint / vitest 回归、Tauri 后端 Clippy 与 `scripts/tests` 的 Python 回归。测试在临时目录、临时数据库、模拟记录或隔离子进程中运行；不会打开个人数据库、连接真实 MySQL/MongoDB 服务或修改真实自启动项。

前端 lint 当前只要求 0 error，既有 warning 仍会输出，本表不把 lint 结果写成无警告通过。

前端回归使用 vitest（测试文件首行声明 `// @vitest-environment jsdom`），并用 `vi.mock` 模拟 `@tauri-apps/api` 的 `invoke`，不启动真实 Tauri 窗口。Tauri 命令层本身只有编译与 Clippy 检查，业务规则由核心库回归覆盖。

## 专用环境验证

普通回归中唯一的 `ignored` 项是 `src/updater.rs` 的隔离等待夹具，由更新回归在子进程中调用，不计入普通通过数。

真实 MySQL 私网库、MongoDB 文档库、GitHub Release 发布和安装器安装 / 升级 / 卸载不在 `scripts/verify.ps1` 中执行：它们需要凭据、网络或发布权限，不能在普通回归中声称已通过。安装器的真实安装、升级与卸载检查位于 `.github/workflows/package-release.yml`，由发布流程按需触发。

`web/markdown-editor/` 与 `assets/markdown-editor/` 是旧原生界面使用的离线 Markdown 编辑器资源构建工程（由 `scripts/build-markdown-editor.ps1` 打包）；当前 `desktop/` 客户端改用自带 CodeMirror 组件，不再引用该资源包，普通回归也不构建它。
