# 数据建模与报表工坊

从「工具」中打开「数据建模与报表工坊」。功能使用办公台已有的 SQLite 数据库，不会另建一个每日入口或独立客户端。

## 导入 Excel

1. 在「导入工作簿」中选择 Excel 文件。每个工作表都有单独的预览和导入设置；勾选要导入的工作表，一个工作簿里的不同 Sheet 可以分别落到不同数据表。
2. 为每个 Sheet 填目标表名和数据起始行。可以按 Excel 列号映射字段，也可将字段设为固定值；字段类型可选文本、整数、浮点或精确小数。把编号列设为文本可保留前导零。
3. 可设置结束标记或跳过关键列为空的行。检查预览和字段映射后选择新建、追加或替换目标表数据，再开始导入。

导入会检查源文件是否在预览后发生变化。某个 Sheet 出错时本次多表导入会整体回滚。追加和替换只影响选中的目标表。

## 管理数据表和刷数

在「管理数据表」选择一张表并读取数据。可以编辑当前页单元格、添加自定义字段或重命名字段。新增字段后可设置统一固定值，也可用该行其他字段配置加、减、乘、除的规则。

先保存规则，再勾选确认并执行「规则刷数」。执行前需要读取当前表以确认数据版本；类型不匹配、除数为零或数据已被其他操作修改时会报错，不会留下部分刷数结果。精确小数以文本保存，避免 SQLite 浮点舍入。

## 从空白模板设计报表

在「报表规则与动态行」设置模板编号和名称、动态行来源表、分组字段及筛选条件，添加结果列并选择计算规则。规则可对单表分组求和，也可按多个字段将两张表关联、筛选右表后汇总；结果支持加减乘除。关联条件和筛选值会作为参数传入查询。

可以设置排序、行数限制、动态数据起始行和分组起始列。通过单元格网格添加固定文字或计算格，也可以输入超过网格范围的行列位置。动态数据行数增加时，动态行之后的自定义单元格会相应下移。

每次点击「保存新版本」都会留下一个模板版本。生成预览后，先保存对应模板版本再导出 Excel。生成记录保存使用的模板版本、数据版本、输出路径和文件 SHA-256；数据或模板变化后须重新生成预览。历史模板版本可以分别加载，或选择多个版本生成一个多工作表 Excel。

## 规则范围

模板规则由界面中的字段、表和运算组成，不执行手工输入的任意 SQL。跨表关联当前通过一个或多个字段相等条件完成，并支持右表等值筛选。算术使用固定小数精度，输入值超出精度、结果除零或字段类型不匹配会明确报错。
