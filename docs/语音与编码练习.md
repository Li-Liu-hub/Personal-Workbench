# 语音与编码练习

## 每日单词

点击“朗读单词”，或展开“句子朗读 / 跟读”朗读题中英文、粘贴的句子及自己的英文答案。普通 / 慢速分别为 1.0 / 0.75 倍速；美音使用 af_maple，英音使用 bf_vale。语音独立于负责翻译、讲解和批改的 GGUF 模型。

学习页始终显示模型启动栏，并提供“模型管理”。模型仅保留 **Spark-X2.6-4B-Q4_K_M**（讲解、批改、生成英语练习）和 **Kokoro v1.1**（英文朗读）；在启动栏选择后点击“启动模型”，两者可同时运行。旧设置中的其他文本模型会切回 Spark2.6 Q4；同名模型文件的自定义位置保留，可在练习设置中重新定位。

Kokoro 首次朗读时加载，也可在“语音设置”提前启动。连续朗读同一口音复用同一个后台进程和模型，避免每段文本重新加载；切换美音 / 英音时重新加载对应配置。模型保留至手动停止或退出，取消生成会回收当前语音进程；停止播放保留已经加载的语音模型。首次加载和整段新文本生成仍需要时间，重复内容使用音频缓存。

点击“听写练习”，作答前不显示目标拼写、音标和 AI 参考侧栏；可重复播放后填写单词，点击“检查拼写”或 Ctrl+Enter。本地比较忽略大小写与首尾空白，不忽略内部字符。正确为 100%，错误为 0%，结果按原掌握规则累积，查看答案计为辅助或不会记录，历史不改写。听写不等同于口语发音评分。

首次在“语音设置”下载 Kokoro 与独立 Python 环境，约 180 MB；模型为 Kokoro v1.1 的 int8 ONNX 版本，使用 sherpa-onnx 1.13.3 CPU 推理。之后离线运行，无需系统 Python、GPU 或 API Key。所有下载文件校验固定 SHA256，安装保留旧目录以便恢复。后台生成与播放可停止，取消回收本客户端的子进程；最近 100 段 WAV 按文本、语速、音色和生成脚本版本缓存。一次英文最多 1500 字符。

运行环境位于当前数据目录 `learning-runtime`，更新客户端保留该目录。缓存和模型不随记录导出；换电脑后重新下载。单独安装可使用仓库脚本 `scripts/install-learning-runtime.ps1 -Root <数据目录>/learning-runtime -Component Speech`。

## 讲解与追问

刷题王、每日单词和百科关联练习共用 `src/ui_components/tutor.rs` 的讲解面板。对话记录与追问输入框各自带垂直滚动条；输入长代码或多行文字时，输入区高度保持有限，发送按钮保留在下方。

光标在追问输入框时，**Ctrl+Enter 发送追问，Enter 换行**。光标在左侧作答区时，Ctrl+Enter 仍提交练习答案。空白追问和模型处理期间不会重复发送；参考解答、复制回答与失败重试仍使用同一套面板。

## 编码题

刷题王点击“编码练习”或选择“编码题”，直接编辑程序、点击“运行样例”，根据编译错误、标准输出、标准错误与逐组对比修改，再“提交 · 样例判题”。源码修改后必须重新运行，旧测试结果不能提交为新源码的证据。

- Java：使用 `JAVA_HOME/bin` 或 PATH 上的 JDK；主类为 `Main`，UTF-8 源文件，Java 17 基线。
- C：使用 TinyCC 0.9.27 Windows x64 便携包；页面或“练习设置 → 离线语音与编码环境”可以安装，下载约 0.5 MB。定位到自己的 `learning-runtime/tcc`，不更改系统 PATH。
- 每题提供完整输入约定、初始源码、参考程序、精确知识点与多组输入 / 输出。共 12 题、39 组样例，包含空集合、负数、重复元素、不匹配括号与缺失目标等边界。
- 仅忽略行尾空格、CRLF / LF 以及最终换行；中间空白、顺序、重复值等仍参与比较。非零退出、编译失败、超时及截断输出不能通过。分数按通过样例占全部样例的比例计算。
- 编译上限 20 秒，每个样例上限 3 秒，标准输出 / 错误各限 64 KiB，单份源码限 64 KiB，子进程作业合计提交内存上限 2 GiB；可点击“停止运行”。临时目录只存本次代码和输入，结束清理；退出或取消回收同一作业内的后代。

本地程序以当前用户身份执行，资源限制不是文件和网络隔离沙箱，适用于自己编写的练习代码。样例通过不证明所有输入正确，也不自动验证算法复杂度、是否采用指定 API 或金额类型；这些要求可再使用 AI 讲解和人工检查。看过参考答案后仍遵循原辅助练习规则。

未提交源码进入待完成记录；提交成绩保存题目快照、当时源码、编译状态、每组输入 / 预期 / 实际输出 / 错误与耗时，随刷题王及全量导出。旧题和成绩不改写。百科中的“配套题目”可直接选题，题目中的“关联知识”可回到原文，切换前保存已有作答。
