# 刷题王题库规范

版本：v0.9.0。面向个人计算机基础与 Java 后端工程训练，优先让使用者知道下一步练什么、练习目标是什么、如何验证自己的答案。

## 训练分类

| 类别 | 范围 | 作答产物 |
| --- | --- | --- |
| 八股题 | 语言、Java/JVM、并发、操作系统、网络、数据库与框架 | 原理、具体例子、适用边界 |
| SQL 训练 | 建模、约束、CRUD、连接、聚合、索引与事务 | SQL 或概念解释、实际结果与边界 |
| Linux 命令 | 文件、权限、进程、日志、网络与管道组合 | 命令、参数解释、输出含义和权限条件 |
| 代码实战 | 阅读推演、数据结构、基础算法、实现与修复 | 代码、输入输出推演、边界测试 |
| 排障与调优 | 最小复现、日志指标、故障定位、性能实验与回归 | 现象→证据→假设→修复→验证 |
| 工程设计 | 业务不变量、失败处理、幂等、一致性、容量与发布 | 方案、失败路径、取舍和验证方法 |
| 项目实战 | 多文件源码阅读、修改、测试与修复说明 | 修复 ZIP、真实测试报告、修复解释 |

旧类别仅做兼容映射：场景题→工程设计，SQL 命令→SQL 训练，Bug 排查/性能调优→排障与调优，项目修 Bug→项目实战。保留旧题 ID、存储的题干、原分类及历史快照；界面按新名称展示。导入的自定义类别仍可在专项菜单选择。

## 能力方向与阶段

题型与能力方向分别存储。八个方向为：编程与算法、Java 与并发、数据库、操作系统与 Linux、网络与 Web、工程可靠性、测试与排障、性能与交付。

1. **基础理解**：解释概念，准确推演短代码或小样例，识别基本边界。
2. **应用实现**：根据明确场景实现代码/命令/查询，设计测试与失败处理。
3. **综合进阶**：连接多个知识点完成工程方案、复杂排障或项目修复。

推荐训练先安排八个方向的基础摸底。每个方向两道不同基础题的最新独立成绩达到设置的达标线后，允许推荐应用题；两道不同应用题独立达标后，允许推荐进阶题。项目题还要求 Java 与数据库方向至少进入应用阶段。未达到阶段要求的题仍可通过专项或自由混合手动练习。

阶段仅用于安排训练。它与某一道题默认连续五次独立达标的“掌握”状态不同，也不代表该领域能力认证。参考答案、AI 提示及讲解后的辅助练习保留分数和历史，但不用于摸底完成、阶段解锁或独立掌握连续次数。后续独立低分会反映到阶段判断中。

摸底后先平衡能力方向，再按权重安排弱项、未练新题、巩固和已掌握题。权重分别为 150、100、60、1；已掌握题可按设置彻底停止。尽量避开最近 16 道工程题；不足时允许重复。当前算法采用可解释的规则，不使用额外模型推断用户能力，不生成精确学习效果预测。

## 每题必备内容

- 稳定且唯一的 `id`；修订题库时不得用已有 ID 表示完全不同的问题。
- `kind`、`topic`、标题、完整题干、参考解答及来源。
- 评分点 ID 唯一，每点有明确描述与分值，合计为 100 分。
- 新题的 `training` 包含能力方向、1～3 级难度、练习目标及作答要求。
- 对代码给出语言版本、输入输出、空值/越界等契约；SQL 给出建表和样例；排障给出日志、指标或可观察现象。
- 参考解答包含关键原因与验证方式，不能只列技术名词或只给一段无法解释的代码。

示例元数据（其余字段参见 `assets/foundations.json`）：

```json
{
  "training": {
    "area": "编程与算法",
    "level": 2,
    "goal": "通过循环不变量实现首个匹配位置的二分查找",
    "deliverable": "提交 Java 实现，说明边界及重复值测试。"
  }
}
```

新建工程题应提供上述元数据。旧题及旧格式导入可省略 `training`，客户端按已校对的旧题能力映射或兼容规则补充展示、导出；不回写或覆盖旧题 JSON。已保存的自定义元数据优先使用。

## 验证边界

- 代码实战和 Linux 命令由 AI 作文本批改，不声称已经编译或执行命令。
- 可运行 SQL 在独立内存数据库建表与灌入样例，运行后还原；查询/修改结果与参考比较。
- Java 项目只使用固定原始测试，上传的测试代码不作为验收依据。
- 4B 模型给出分项评分和简短讲解；允许合理的等价方案，评分依据须来自学生答案。实际测试结果与模型分数分别展示。
- 新题导入采用追加和去重，已有题目、练习答案、待完成记录和历史快照保留。练习导出携带题目目标与难度。

## 原工程主线

共 70 题：八股 13、SQL 14、Linux 7、代码实战 10、排障与调优 16、工程设计 9、项目实战 1。每个能力方向至少有两道基础题及两道应用题。包含 11 道可运行 SQLite 题和一个 Java 多文件项目；后续扩充题目数量时仍需遵守本规范并验证参考答案。

参考资料采用官方或维护者文档：[Dev.java](https://dev.java/learn/)、[SQLite SQL](https://www.sqlite.org/lang.html)、[HTTP 语义 RFC 9110](https://www.rfc-editor.org/rfc/rfc9110.html)、[Linux man-pages](https://man7.org/linux/man-pages/man7/pthreads.7.html)、[Git revert](https://git-scm.com/docs/git-revert)。训练题和个人推荐规则为本项目原创设计。

## 指令知识点专项

另有 376 道指令专项，通过 `knowledge_ids` 关联 358 个知识点，`tags` 标注语言、主题和练习形式。默认推荐仍走上述 70 题工程主线；按类别、自由混合和知识点入口可访问专项。专项不改写题目快照，沿用独立作答、掌握与复习规则。

18 道可运行窗口函数实操都带实际表结构和样例，每题另有边界辨析。参考 SQL 必须在临时库中通过，错误结果应失败，并验证运行后回滚；不能仅因为 SQL 能执行就判正确。详情见 [知识点与游戏扩展](知识点与游戏扩展.md)。
