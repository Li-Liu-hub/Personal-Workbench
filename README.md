# 个人办公台

Rust 原生 Windows 桌面工具。直接打开使用，集中管理个人记录、文档和练习。当前版本：**0.9.0**。

## 项目理念

**极致轻量，极致简约。**

- **极致轻量**：降低内存占用、启动耗时和操作延迟，按需加载资源，减少依赖、后台任务和重复计算。
- **极致简约**：统一布局，减少层级、弹窗和无关说明，用少量操作完成日常工作。

新增能力以个人实际需要为依据，保留已有数据与升级兼容。本地 AI 按需用于练习评分、讲解和翻译题生成，独立于轻量客户端；不加载模型时没有推理服务常驻。

界面采用浅色分组导航和统一分段切换；学习页左侧作答、右侧讲解，讲解栏可收起。底部操作固定可见，记录本整行可点击查看详情。`Ctrl+Enter` 提交练习答案。已有自定义主题、数据和练习记录保留。

## 使用

打开 `dist/个人办公台.exe`。已有数据位置由旁边的 `personal-desk-data-path.txt` 指定，移动程序时请一并保留。

仓库提供源码、测试和资源；`dist/` 是本机构建产物，不随 Git 上传。从源码使用时，先按下方“开发”章节构建。

| 使用范围 | 所需环境 |
| --- | --- |
| 记录管理、写作、日志、SQLite 练习、导出 | Windows x64 客户端 |
| AI 批改、讲解、追问和翻译题生成 | 在练习设置中选择本地 GGUF 模型及 `llama-server.exe` |
| Java 项目实际编译与测试 | JDK 17+，`javac` 和 `java` 可从 PATH 找到 |

记录页可直接搜索和分类筛选，宫格用于浏览；账号、联系人和物品支持列表内编辑。写作从“新建文档”或“生成日志”开始；学习从题型或英语练习方式开始，作答后点击提交，也可先在右侧请求讲解。

### 写文档

在 **文档写作** 中直接新建、输入标题和正文，停止输入后自动保存。顶部固定提供返回、写作/预览、生成日志和新建；更多菜单提供分类、格式插入和 Markdown 导出。

**生成日志**使用本机当前日期作为标题，例如 `2026-10-21`。同一天再次点击会打开已有日志，保留正文及所属图书。文档可拖到一起组成图书；拖入已有图书或其中的文档时，保留图书名称并进入原图书，自动打开被拖动文档的标签页。同一本图书内拖放不会另建图书，标签页使用文档标题。

写作使用原生 egui 编辑区，Markdown 预览采用开源 [egui_commonmark](https://github.com/lampsitter/egui_commonmark)。正文使用无边框纸张布局，支持原生文本撤销。旧版本的台内文本及恢复草稿会复制到写作库，原文件保留；外部文件索引保留在历史数据和导出中。

### 刷题王与每日单词

- **刷题王**：内置 70 道原创工程题，默认推荐训练，也可专项练习或自由混合，支持 JSON 题库导入。
- **每日单词**：离线抽取 [ECDICT](https://github.com/skywind3000/ECDICT) 中带 `ielts` 标记的 **5040** 个词条，包含音标和中文释义。支持释义、造句、中译英、英译中、语法及混合训练，以雅思为主，兼顾日常与技术语境；每日目标默认 20 个不同单词。这是开源词库中的 IELTS 分类，不代表考试官方完整词表。
- **AI 批改**：4B 模型负责分项打分和简短中文讲解，客户端校验并加总完成度。SQL 题会附带真实 SQLite 执行结果供模型参考；Linux 命令仍只作为文本批改。可一键复制题目、自己的答案、执行结果和模型反馈，交给其他模型继续分析。
- **记录本**：两个模块独立记录每次作答、完成度、分项反馈、题目快照和模型名称，按第 1、2、3…次排列，可查看变化和再次练习。
- **掌握规则**：默认连续 **5 次独立作答完成度 ≥85%** 后极低频抽取，也可设为停止抽取。独立作答未达标会重新累计；查看参考解答或得到 AI 提示后标记“辅助练习”，保留分数和历史，但不计入独立掌握连续次数。调整规则会重算掌握状态，不改变历史成绩。
- 答案在评分前保存，评分失败不写入虚假成绩，可重试或从待完成记录恢复。“不会，查看答案”会记录本次完成度为 0。

#### 讲解、追问与学习进度

右侧 **讲解与追问** 提供“AI 解答”“提示一步”“解释反馈”和自由追问，自动带上当前题目、自己的答案与评分反馈；可以不提交答案，先请求讲解。“参考解答”无需启动模型。每道题的已发送对话独立保存，可复制回答，并随记录本导出。

上方提供 **启动模型**及随状态变化的**停止模型 / 停止生成 / 取消启动**，显示加载/读取/生成状态、耗时、生成 token 数、真实 token/s；运行时暂未返回统计时显示“—”。回复逐步显示。模型加载后即使没有生成任务，也能停止并释放资源；停止生成时也会关闭本客户端的推理进程，再次练习可重新启动。停止不会删除自己的答案，失败可重试。页头区分今日练习量、已练项目、独立掌握和待巩固项目。

#### 题库与推荐训练

| 类型 | 主要内容 | 起步题数 |
| --- | --- | --- |
| 八股题 | 语言、Java、操作系统、网络、数据库与框架原理 | 13 |
| SQL 训练 | 数据建模、查询、连接、聚合、约束、增删改和事务 | 14 |
| Linux 命令 | 文件、权限、进程、日志及管道组合 | 7 |
| 代码实战 | 推演输出、数据结构、基础算法、集合、金额和并发代码 | 10 |
| 排障与调优 | 最小复现、边界测试、线程/连接故障、性能实验和版本回退 | 16 |
| 工程设计 | 业务不变量、失败处理、幂等、分页、流量保护和发布兼容 | 9 |
| 项目实战 | Java 多文件订单服务修复及固定测试 | 1 |

“训练路线”按编程与算法、Java 与并发、数据库、操作系统与 Linux、网络与 Web、工程可靠性、测试与排障、性能与交付八个能力方向组织。题型用于选择练习方式，能力方向用于发现知识缺口；整体以个人 Java 后端工程训练为主线，后续可继续扩展。

出题字段、难度标准、参考解答与验证要求见 [训练题库规范](docs/训练题库规范.md)。

推荐训练先在各方向安排基础题。每个方向有两道**不同的基础题独立达标**后进入应用阶段，两道不同应用题独立达标后进入进阶；默认达标线沿用练习设置中的 85%。看过答案或接受 AI 帮助的成绩保留，但不用于解锁阶段。进阶项目还要求 Java 和数据库基础达标。进入阶段与“连续五次独立达标掌握某题”分别计算。

选题先平衡能力方向，再优先弱项与未练新题，近期题目尽量避开；已掌握题按设置停止出现或低频复习。每题显示推荐原因、阶段和目标，展开“作答要求”可查看交付标准。专项及自由混合允许自行选择进阶题；原题名和历史分类不重写，界面兼容映射旧类别。

代码实战按文本和评分点进行 AI 批改；实际编译、运行测试目前由 Java 项目实战提供。Linux 命令只作文本练习，不在个人机器执行。路线进度用于安排学习，AI 分数仍需结合实际验证核对。

点击单词下方的造句、翻译或语法按钮，会围绕**当前这个词**继续练习；“换一道/下一题”抽取新的词或混合练习。各方式分别记录完成度，认识词义不会自动算作会造句。造句没有唯一标准句子；语法采用内置校对过的错误句与正确句，覆盖主谓一致、完成时、情态动词、介词与不定式等。翻译题由本地模型围绕目标词生成并缓存，原作答保留题目快照；合理的不同译法和表达可得分。

混合方式依次覆盖五种训练方式，单词按掌握情况随机抽取，进度与选择会保留。模型推理只携带本题和最近若干条对话，完整已发送对话保存在本地记录中。

#### 项目修 Bug

首个练习是 **Java 17 多文件订单服务**，包含商品、库存、订单、仓库和服务等主源码，以及 9 个原始回归场景，涉及重复扣减、非法数量、失败不应改变数据、请求冲突和并发一致性。

在题目中 **导出项目 ZIP → 在自己的编辑器修复 → 导入修复后的 ZIP → 运行项目测试 → 提交 AI 点评**。测试始终使用内置原始测试，不采信上传 ZIP 中被修改的测试。源码、实际编译/测试输出和 AI 反馈保存到本地，并随全部导出保留。以前作答的源码和测试结果保留在历史快照中。

这项练习需要系统已安装 JDK 17+，并能找到 `javac`、`java`。编译和测试在临时工作目录及后台子进程中执行，有超时和输出上限，不使用个人数据库作为工作目录。当前是一个内置项目练习，不是任意项目的通用构建器。

#### SQL 练习

内置 **14 道 SQLite 题**：11 道可运行练习，从筛选排序、条件修改开始，覆盖连接、聚合、NULL、窗口函数、新增、删除、UPSERT 和转账；另有 3 道概念题，练习计数、主外键和事务。每题提供场景、建表语句、样例数据及参考讲解。

在编辑区直接写 SQL，点击 **运行 SQL** 查看查询结果、受影响行数和样例验证结果；无需启动模型，也不计为一次正式作答。支持多条语句和 `RETURNING`。然后点击 **提交 · AI 批改**，重新运行当前 SQL 并结合实际结果评分；执行记录随本次成绩进入记录本及导出。

训练使用与办公台相同的 SQLite 引擎，但在**独立内存数据库**中自动建表、灌入样例。运行在托管事务中进行，成功、出错或超时后都还原数据；每次运行从相同样例开始。无需填写 `BEGIN`、`COMMIT` 或手动重建表，不接触个人 `desk.db`。查询结果与参考结果比较，修改题则查询修改后的表状态再比较；“样例通过”和 AI 分数分别展示，样例通过不代表覆盖所有边界。

SQL 使用 SQLite 语法，不模拟 MySQL 锁、并发或服务器行为。一次最多 40 条语句、200 行结果，并设置执行预算，避免错误递归卡住界面。概念题填写文字，不执行答案。旧题库仍可导入；仅带可运行 `sql` 配置的题目显示执行按钮。

#### 本地模型

本机预设使用 [Spark-X2.6-4B](https://github.com/XHToken/Spark-X2.6) 的 `Q4_K_M` GGUF，通过独立 `llama-server.exe` 运行。模型及运行组件放在 D 盘，不打入客户端 EXE，也不提交 Git。

默认位置：

```text
D:/models/llm/spark-x2.6/4b/Spark-X2.6-4B-Q4_K_M.gguf
D:/models/llm/runtime/llama-b11669-cuda12.4/llama-server.exe
```

在任一练习页的 **练习设置** 可更换模型和运行程序。可以一键启动，也会在评分、讲解或生成翻译题时按需加载；默认空闲 120 秒自动卸载，也可手动卸载。请求只发往本机回环地址。4B 的评分、翻译和讲解可能有误，记录本保留原答案、实际测试结果和模型反馈，方便复制给其他模型核对。

### 开机自启动与更新

**设置 → 启动设置 → 开机自启动**。只登记当前用户的程序路径；取消勾选即关闭。已开启时，移动 EXE 后手动打开一次正式版可更新路径，未开启时不会自动开启。

左下角 **更新 → 检查更新 → 安装更新并重启**。开发端构建后发布到 `dist/updates/latest.json`，使用端在程序内安装，不需要手动替换文件。当前是本机更新源，未配置远程发布服务；Rust 代码改动仍需开发端编译，安装后重启生效。

更新替换程序，保留个人数据目录，并在安装前创建数据库备份。保存失败或后台操作未完成时会阻止安装。模型权重不随客户端更新重复下载。

## 数据与导出

- 默认数据目录 `%LOCALAPPDATA%/PersonalDesk`；程序旁的位置文件可覆盖它。
- `desk.db` 保存记录、文档正文、草稿、版本、练习答案、成绩和设置。主题图片及旧版原件保留在数据目录。
- 账号密码按普通文本保存，没有登录、权限校验或锁定流程。
- 各模块可导出；全部导出包含可读 JSON、Markdown 文档、练习题目和完整记录本、旧版原件及数据库快照。
- **快捷路径和历史外部文档索引只保存地址，不打包指向的外部文件夹。**模型权重、浏览器登录资料不打入数据导出。
- 导入使用事务，导出先写临时压缩包并验证，再替换目标。升级保留旧表、原件和草稿；建议定期全部导出。

```powershell
.\dist\个人办公台.exe --import-data 输入.json
.\dist\个人办公台.exe --export-all 输出.zip
```

账号导入 JSON 使用 `accounts` 和可选 `websites` 数组。练习页“导入题库”使用 `version: 1`、`cards` 数组；每题需要稳定 `id`、`kind`（`engineering` / `word`）、标题、题干、参考答案与总分 100 的 `rubric`。同 ID 不覆盖现有题目。练习记录通过模块导出和全部导出保存，题库导入只添加题目。

需要 Windows x64、Rust 1.95+、`x86_64-pc-windows-gnu`、MSYS2 UCRT64 GCC。普通办公功能无需 WebView2 或模型运行环境。

```powershell
rustup target add x86_64-pc-windows-gnu
$env:MSYS2_UCRT64_BIN = 'D:\msys64\ucrt64\bin'
.\scripts\build.ps1
```

构建脚本执行格式、Clippy、测试和发布编译。运行中的 EXE 不会被直接覆盖，只发布更新包。开发时将 `CARGO_TARGET_DIR`、`TEMP`、`TMP` 指向不含中文的目录，避免 GNU 链接器路径兼容问题。

```powershell
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
```

### 扩展方式

- 新工程题通过稳定 ID、题干、参考答案和评分点接入题库；SQL 题可附建表、样例与可执行验证配置。
- 页面交互放在 `src/app/`，数据访问和迁移放在 `src/db/`；公共列表、分类和卡片复用 `src/ui_components/`。
- 模型运行、英语练习、SQL 执行和项目测试各自独立，新增能力按需调用，保持客户端空闲时轻量。
- 涉及持久化和迁移的改动需验证旧数据、草稿和导出兼容；详细约定见 [开发文档](docs/开发文档.md)。

普通测试不启动模型、不更改真实自启动项、不使用个人数据库。开发版隔离截图入口不编入正式版。项目采用 [MIT](LICENSE)；词库来源及许可证见 [assets/ECDICT-LICENSE.txt](assets/ECDICT-LICENSE.txt)。详细设计见 [开发文档](docs/开发文档.md)。
