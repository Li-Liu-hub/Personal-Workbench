# 子图书操作修复（v0.15.50）

## 原因与修改

- 正文编辑器旁的递归目录 `child_books` 仅接入展开、拖动和页面操作，缺少图书的右键菜单；未打开正文时的图书目录已有菜单。
- 为每一级子图书接入“重命名图书”和“删除图书”，在正文渲染结束后派发动作，复用已有图书编辑窗和删除确认窗。页面删除与图书删除显式区分。
- 保存已有图书后刷新名称及目录缓存，保留当前目录、选中页面和未保存正文；新建图书继续进入新图书。
- 不迁移或直接修改用户数据库；删除沿用原墓碑、后代隐藏、修订冲突与草稿保护流程。

## 验证范围（2026-11-03）

- 发布快照以 v0.15.48 的已发布源码和已验证的 v0.15.49 小工具启动修复为基础，加入本次改动。共享主目录其他未完成改动不计入验证范围。
- 新增模拟鼠标交互回归：正文编辑目录与未打开正文的目录中，二级和三级图书的右键菜单、重命名保存、名称和父级持久化、当前目录与未保存正文保留、删除取消、再次打开菜单确认删除及重启结果。
- 新增子图书删除回归：正在编辑其后代时先保存正文、关闭被删除页面及悬浮窗、保留父图书和父页，过期页面不能重新保存，重启恢复草稿不会复活已删除内容。
- 现有删除回归继续检查宫格/列表、相邻页面切换、小窗口布局、保存冲突阻止删除及其他页面草稿保留。
