# 简历编辑

侧栏进入“简历”，左侧修改个人信息、教育背景、实习与项目经历、技能，右侧显示 Typst 实际生成的页面。所有文字作为普通文本处理；无需编写 LaTeX 或 Typst。

支持栏目、经历和要点的新增、删除、上下移动；支持替换照片、隐藏照片、字号与左右页边距设置。输入停止一秒后自动保存并后台排版，也可按 Ctrl+S 保存。预览可放大至适宽尺寸的 3 倍，支持滚动查看；超过一页时显示翻页与调整提示。预览最低以 300 PPI 生成，按窗口尺寸、屏幕缩放与放大倍数提升至最高 600 PPI；“适宽 × 1.00”表示当前预览栏宽度。编译期间仍可编辑，新预览过期时会提示等待更新。

原版版式使用随简历资料保存的 Noto Sans SC 常规 / 半粗字体，保持全页居中的姓名与联系信息、右上角照片、蓝色栏目条、青色项目条以及黑色重点加粗。原版正文 10.5 磅、行高 14.72 磅、项目要点间距 7 磅、技能条目间距 3 磅，上下边距分别为 6.5 / 3 mm。正文行高、项目和技能间距均可分别调整；“恢复原版版式”恢复这些参数并保留正文。条目和要点里的“重点加粗”每行填写一个要加粗的原文词句，无需输入排版代码。

个人资料保存在 `docs/简历`。此目录含 `resume.json`（可编辑资料）、`resume.typ`（程序生成的排版模板）、`photo-*.png`、原始 PDF、`简历_编辑版.pdf`（生成结果）。程序保留上一份已保存 JSON 为 `resume.previous.json`。原始 PDF 不会被生成过程覆盖。PDF 解析用于本次初始资料整理，客户端不提供任意 PDF 自动转表单功能。

`fonts/` 保存与原 PDF 相同的字体，迁移和备份时需一起保留。`resume-format.json` 是初次恢复的格式备份，仅用于补回旧版程序可能遗漏的格式字段；不会替换简历正文，也不会恢复新版中明确删除的加粗。没有原版字体的资料会使用本机微软雅黑，字形和换行可能不同。

本地项目首次进入简历页会定位项目 `docs/简历` 并记录目录。部署到其他电脑时默认使用办公台数据目录内的 `docs/简历`；可从“更多 → 选择简历资料文件夹”指定备份所在目录。个人资料不编入程序、不进入源码提交或公共发布包。迁移时复制整个简历目录，或通过“备份资料”导出。办公台的“导出全部数据”也包含已绑定的简历资料。

保存前校验文件修订，外部编辑过的文件不会被旧界面覆盖，保存失败会保留内存编辑并阻止正常退出。保存失败时仍可调整左侧内容、刷新草稿预览或导出到指定 PDF；草稿预览不会自动覆盖目录内已保存的 PDF。遇到外部修改冲突，可点击“备份外部版本并保存当前编辑”：先保留独立的 `resume.external-*.json` 外部版本，再保存当前编辑；后续自动保存不会覆盖这份独立备份。也可在“更多 → 重新读取已保存内容”重新加载外部版本，此操作明确放弃当前未保存内容。

## Typst 运行时

采用官方 Typst 0.15.1 Windows x64 独立程序，首次下载约二十余 MB，解压后的引擎约 50 MB。编译和预览离线运行，优先使用简历目录的原版字体，缺少时使用本机微软雅黑，不启动浏览器或常驻服务。官方源码和许可证见 <https://github.com/typst/typst>，说明见 <https://typst.app/open-source/>。

执行 `scripts/install-resume-runtime.ps1` 可下载固定版本并验证 SHA-256；也可在简历页“更多 → 选择 Typst 引擎”选择已有的 `typst.exe`。程序依次发现同目录 `tools/typst/typst.exe`、项目开发运行时、系统 PATH。便携交付时将引擎、LICENSE、NOTICE 放入程序旁的 `tools/typst`；安装包可由打包脚本一起包含引擎。个人简历和照片不随公共程序包发布。

排版在独立后台任务执行，每次使用临时 JSON、模板和照片快照。正文不会作为 Typst 代码执行；PDF 与 PNG 由同一份数据及模板生成。任务有超时、内存和日志限制，失败保留原 PDF 和界面编辑。

## 验证

自动回归覆盖保存重启、上一版备份、外部修改冲突、损坏文件保护、照片复制缩放、版本与路径验证、简历与全部导出，以及界面编辑保存。真实 Typst 多页与特殊字符测试需显式运行忽略的集成测试。提交前执行项目的格式、Clippy 和测试检查，并检查 1000×680、1280×800 页面与最终 PDF。
