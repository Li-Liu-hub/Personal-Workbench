# 写作悬浮窗与笔记导入

打开“文档写作”中的文档，点击顶部“悬浮窗”。窗口默认置顶，可在简历、浏览器或聊天窗口旁边记录问题和总结。拖动系统标题栏移动，拖动窗口边缘缩放。取消“置顶”后与普通窗口一样使用；主窗口最小化不影响小窗编辑。

标题和正文直接写入原文档，停止输入约半秒自动保存，支持 Ctrl+S。“更多”可复制全文或导出 Markdown。“回到主窗口”先保存并回到同一篇文章；关闭小窗也先保存。遇到修订冲突或写入失败，小窗保留草稿和错误提示。程序退出时沿用原有保存拦截与恢复机制。

图书内文档沿用同一编辑器，打开图书后点击上方文章标题切换。目录中的图书可右键重命名。归组保留正文和标签，继续编辑不创建副本。

## Obsidian 整理导入

`scripts/import-obsidian.py` 用于把本地 Obsidian 笔记整理成图书：按目录归类为日记、工作、学习、项目、求职、私人账号等图书，再通过事务导入。默认映射使用示例目录名（`工作/项目一`、`项目一` 等），可按自己的笔记结构调整脚本中的 `category()`。原仓库保持不变，隐藏配置、插件依赖、助手技能目录和回收站不作为笔记导入。

私人账号笔记按原文导入“私人 · 账号资料”，属于本地写作文档，与办公台的“账号密码”模块是分别存储的。

## 导入与验证实现

`scripts/import-obsidian.py` 使用本地来源分类，先建立数据库一致快照，再复制原件、转换链接并调用 `--import-writing-bundle <JSON路径> [数据目录]`。数据包通过数据库层的一次事务导入，以来源路径登记，重复执行不会覆盖已编辑文档或恢复已删除文档。导入报告和导入前备份放在数据目录的 `import-reports`；原件与图片放在 `writing-assets`，进入图书、文档和完整 ZIP 导出。

普通回归覆盖悬浮窗原生视口输入、最小尺寸工具栏、置顶切换、自动保存、关闭保存失败与恢复、图书打开后编辑，以及导入回滚和重放。数据验收逐篇核对标题、正文、图书和标签，核对 89 份源文件和副本哈希，并比较导入前已有表记录及导出 ZIP 中的正文与附件。
