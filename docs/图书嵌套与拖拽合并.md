# 图书嵌套与拖拽合并

## 0.15.28：子图书展开选择与返回修复

- 图书内部的子图书点击后在原位置展开、收起，不自动进入或切换正文；支持继续展开三级及更深目录，再点击文档打开。
- 选择子图书中的文档后保留父级目录和已展开的图书，搜索可查到后代图书中的文档。
- “上一级”、页面切换、拖拽等目录操作统一在当前正文绘制后处理，避免清空页面后继续绘制导致退出。
- 切换和返回前保存草稿；发现其他窗口修改时阻止切换，保留当前草稿和目录。
- 从已选择的子图书文档新建或删除页面，使用该文档所属图书。
- 继续通过原有更新链发布，日常入口仍为 `dist/个人办公台.exe`。

更新批次：0.15.14。

- 在文档列表中，把一份文档拖到另一份文档上，生成一本图书，两份文档成为其中各自独立的页面。
- 在图书内的文档列表或编辑器左侧目录中，同样的拖动会生成子图书，可继续嵌套。
- 把图书拖到另一图书上，可放入目标图书；不能把图书拖入自身或后代。
- “创建图书”及编辑器目录中的“新建子图书”可直接创建当前目录下的图书。
- “上一级”返回父目录；返回图书目录后，右键子图书的“移到上一级”可将其移出一层。
- 合并保留页面编号、正文、标签和日志关联，先保存当前编辑内容，保存冲突时停止移动。
- 删除图书会隐藏其全部子图书及页面，保留原有删除和保存冲突保护；导出包含图书层级。

本次图书改动基于 0.15.12 单独验证，最终纳入并行工作的 0.15.14 合并发布包；保留该发布包的其他已发布功能。现有数据库只读副本的升级验证通过，图书与写作记录保持完整。
常规验证：276 项 Rust 测试、13 项 Python 测试通过，21 项依赖专用环境的 Rust 测试未执行；格式与 Clippy 检查通过。
